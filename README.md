# GitHub 资源上传

将 Tau 中插入的图片、音视频和附件上传到 GitHub，正文保存可直接访问的资源地址。需要支持上传插件的 Tau 0.59.0 客户端。

## 使用

1. 从插件中心安装并启用本插件。
2. 在「设置 → 资源存储」选择「上传插件」和「GitHub 资源上传」。
3. 填写账号与存储位置，点击「保存并使用」。
4. 在笔记中插入图片或附件，确认正文和浏览器都可以访问返回的地址。

GitHub 令牌需要目标仓库的 Contents 写权限；仓库与分支须已存在。建议使用专门的公开资源仓库。未配置公开地址时使用 GitHub 返回的下载地址。

路径前缀可为空；公开地址前缀可填自定义域名，返回地址会在其后追加路径前缀和文件名。不要填临时签名 URL。图片压缩由 Tau 的上传压缩开关统一控制。

## 常见问题

- 上传失败：检查凭据、目标桶或仓库、分支及网络；错误不会自动改存别处。
- 上传成功但无法打开：检查公开读取策略或自定义域名。插件不会修改 ACL。
- 独立窗口上传：保持 Tau 主窗口打开，上传插件须已启用。
- 资源目录同步是另一个功能，本插件不执行数据库同步或冲突处理。

## 开发

使用 pnpm：`pnpm install --frozen-lockfile`、`pnpm test`、`pnpm build`。ZIP 位于 dist，可提交插件中心审核。源码采用 MIT 许可。
