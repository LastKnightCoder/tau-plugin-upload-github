# GitHub 资源上传

在笔记里插入图片、音视频或附件时，自动上传到你的 GitHub 仓库，正文里留下一个可以直接打开的链接。发布到博客或分享给别人时，图片也能正常显示。

## 开始使用

1. 在插件中心安装「GitHub 资源上传」，再到插件页的「已安装」里打开它的开关，马上就能用，不用重启。
2. 打开「设置 → 资源存储」，选择「上传插件」，再选「GitHub 资源上传」。
3. 填写访问令牌（需要这个仓库的内容写入权限）、仓库所有者、仓库和分支，仓库和分支要提前建好。建议单独建一个**公开**仓库专门放图片，不然别人打不开链接。
4. 点「保存并使用」，然后在笔记里插入一张图片试试：正文里能看到，在浏览器里打开链接也能看到，就说明配置好了。

想用自己的域名，就在「公开地址前缀」里填上，生成的链接会用这个域名。图片要不要压缩，跟随 Tau 自己的上传压缩开关。

## 常见问题

**上传失败？** 检查账号、仓库、分支和网络。上传失败时不会偷偷改存到别的地方。

**上传成功了，但链接打不开？** 通常是仓库设成了私有，或者自定义域名没配好。插件不会帮你改仓库的可见性，需要你到 GitHub 上设置。

**在单独打开的窗口里插图片没反应？** 请保持 Tau 主窗口开着，并确认插件已经启用。

**能同步我的笔记吗？** 不能。这个插件只负责上传附件，同步笔记请用同步插件。

## 小提醒

- 需要 Tau 0.59.0 或更高版本。
- 访问令牌相当于你的 GitHub 密码，不要发给别人，也不要贴在截图或问题描述里。
